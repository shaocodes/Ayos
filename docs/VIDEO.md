# One-minute video

Record the screen at 1080p with the laptop's own recorder (Windows key + Alt + R, or OBS). Record your voice at the same time or add it after. Keep it to 60 seconds. Do not speed up the model's thinking: if you cut time, show a small "cut" caption so nobody can say the speed is fake.

| Seconds | On screen | Voice |
|---|---|---|
| 0 to 6 | Resolv with the green light. | "When your internet dies, every AI assistant dies with it. This one lives on your laptop." |
| 6 to 14 | Press **Wrong DNS server**. Red light. A browser tab fails to load. | "I just broke this PC's internet on purpose. Wi-Fi says connected. Nothing loads." |
| 14 to 34 | Type the problem, press **Check it**. Let the checks appear. Red dot on DNS. | "Resolv runs an open model locally. It chooses a check, reads the result, and chooses again. It found it: DNS points to a server that does not exist." |
| 34 to 42 | Point the mouse at the green safety line. | "The model does not get the last word. Plain code confirms the evidence before any fix is offered." |
| 42 to 52 | Press **Fix it**. Fixed stamp. Green light. Website loads. | "I approve, it fixes, and it checks again. Every fix can be undone." |
| 52 to 60 | The right-hand panel: model name, "On this PC". | "No cloud. No internet needed. Resolv: the technician that still works when the internet does not." |

Checklist before you upload:

- The video is 60 seconds or less.
- The words "On this PC" and the model name are readable at some point.
- No personal information is visible in the browser (bookmarks, other tabs, account names).
